# Currency-Converter
Currency Converter – Real-Time Exchange Rates (Fetch API) 💱

This project showcases a modern Currency Converter web application that retrieves live exchange rates using a public REST API. Built with HTML, CSS, and JavaScript, it demonstrates practical front-end development skills, asynchronous API integration using the Fetch API, responsive web design, and dynamic user interaction without relying on external frameworks.

🎯 Purpose of the Project
Portfolio

A hands-on project showcasing the ability to build a professional, responsive web application with real-time API integration and dynamic data handling.

Learning

Gained practical experience with JavaScript Fetch API, asynchronous programming (async/await), DOM manipulation, REST API integration, responsive UI development, and error handling.

Placement Ready

Demonstrates strong front-end development fundamentals, API consumption, JavaScript programming, responsive design principles, and the ability to develop real-world web applications following clean coding practices.

Steps:

JavaScript & API Integration

Implemented dynamic functionality using JavaScript and the Fetch API.

Steps:

Retrieved live currency exchange rates from a REST API using the Fetch API.

Performed real-time currency conversion based on user input.

Implemented input validation and handled API or network errors gracefully.
