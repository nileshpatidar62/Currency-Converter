 # **Currency Converter – Real-Time Exchange Rates (Fetch API) 💱**

This project showcases a modern **Currency Converter** web application by integrating a live Currency Exchange REST API using the **Fetch API**. It demonstrates practical front-end development skills, asynchronous JavaScript programming, API integration, responsive web design, and dynamic user interaction using **HTML, CSS, and JavaScript** without relying on external frameworks.

---

### **Portfolio**

A hands-on project showcasing the ability to build a professional and responsive web application that consumes real-time API data and delivers an interactive user experience.

### **Learning**

Gained practical experience in **HTML, CSS, JavaScript, Fetch API, REST API integration, asynchronous programming (async/await), DOM manipulation, JSON handling, responsive layouts, and modern UI development techniques.**

# 🔄 Development Workflow

The project follows a structured front-end development workflow to build a responsive and interactive currency conversion application.

---

## HTML Structure

Developed a semantic and well-organized webpage structure using HTML.

### Steps:

* Created reusable page sections including Header, Currency Selection Panel, Amount Input, Conversion Result, Swap Button, and Footer.
* Used semantic HTML elements to improve accessibility and maintainability.
* Organized content into logical sections for better readability and scalability.
* Designed input fields and dropdown menus for selecting currencies and entering conversion amounts.

---

## CSS Styling

Applied modern CSS techniques to create a responsive and visually appealing interface.

### Steps:

* Designed responsive layouts using Flexbox.
* Implemented modern typography, spacing, color schemes, icons, and UI components.
* Added hover effects, transitions, shadows, and button animations for enhanced user experience.
* Used media queries to optimize the application for desktop, tablet, and mobile devices.
* Maintained a clean and consistent design across all sections.

---

## JavaScript & API Integration

Implemented dynamic functionality using JavaScript and the Fetch API.

### Steps:

* Integrated a live Currency Exchange REST API using the Fetch API.
* Used asynchronous programming with **async/await** for efficient API communication.
* Retrieved real-time exchange rate data in JSON format.
* Calculated currency conversions instantly based on user input.
* Updated conversion results dynamically without refreshing the webpage.
* Implemented proper error handling for invalid inputs, failed API requests, and network issues.
* Optimized performance by minimizing unnecessary API requests and updating only required UI elements.
